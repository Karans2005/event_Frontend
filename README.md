# ✍️ Signature Injection UI

A **Full Stack Signature Injection** web application built using **React.js, Node.js, Express.js and MongoDB**.

The project contains both frontend and backend parts that work together through REST APIs.

---

## ✨ Features

- ✍️ Signature Injection functionality
- 🔗 Frontend and backend integration
- 🌐 REST API
- 📦 MongoDB database
- ⚛️ React.js frontend
- 🚂 Node.js + Express.js backend
- 📱 Responsive frontend
- 🚀 Vercel deployment support

---

## 🛠️ Technologies Used

### Frontend

## 🔄 How It Works

```text
User
 ↓
React Frontend
 ↓
Backend API
 ↓
Express Routes
 ↓
MongoDB
 ↓
Backend Response
 ↓
Frontend
 ↓
User
```

The frontend handles the user interface, while the backend manages the API, routes, database models and server-side functionality.

## ⚙️ Frontend Setup

Clone the frontend repository:

```bash
git clone https://github.com/Karans2005/event_Frontend.git
```

Go to the folder:

```bash
cd event_Frontend
```

Install dependencies:

```bash
npm install
```

Run the frontend:

```bash
npm run dev
```

---

## ⚙️ Backend Setup

Clone the backend repository:

```bash
git clone https://github.com/Karans2005/event_Backend.git
```

Go to the folder:

```bash
cd event_Backend
```

Install dependencies:

```bash
npm install
```

Run the backend:

```bash
node index.js
```

---

## 🔐 Environment Variables

For the backend, create a `.env` file and add the required database/configuration values.

```env
MONGO_URI=your_mongodb_connection_string
```

Don't upload your actual credentials to GitHub.
